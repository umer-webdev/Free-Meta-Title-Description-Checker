# Meta Title & Description Character Counter

> 🔍 A free, real-time SEO tool — [**Live Demo: compteur-de-caractères.fr**](https://xn--compteur-de-caractres-54b.fr/)

A practical and beginner-friendly SEO tool built to help website owners, bloggers, marketers, freelancers, and developers create better meta titles and descriptions for search engines.

This project gives instant feedback on character limits, helps reduce title truncation in search results, and allows users to preview how their page snippet may appear on Google.

Whether someone is publishing a blog post, product page, service page, or portfolio website, this tool makes metadata optimization faster and easier.

## ❓ Why This Project Was Created

Many people publish content without checking whether their title or description is too short, too long, or unclear.

When metadata is poorly written:

- Titles may get cut off in Google
- Descriptions may lose impact
- Click-through rate can drop
- Search listings can look unprofessional
- Important keywords may be missing

This tool solves that problem in a simple, instant way — no login, no installation, no cost.

---

## ✅ What This Tool Does

### 🏷️ Meta Title Checker
- Live character counter
- Recommended target: up to **60 characters**
- **Pixel-width estimate** (~570px Google limit)
- Color alerts when too long or too short

### 📝 Meta Description Checker
- Live character counter
- Recommended target: **155–160 characters**
- Helps users write clearer, more compelling summaries

### 🌐 Google SERP Preview
- Displays a **realistic Google-style result preview** in real time
- Shows blue title, grey URL, and description text
- Lets users see how their listing may appear before publishing

### ⚡ Quick Actions
- **Copy title** to clipboard
- **Copy description** to clipboard
- **Reset all fields** (also: `Ctrl + Shift + R`)

### 🎨 Dark / Light Mode
- Toggle between dark and light themes
- Preference saved in `localStorage`

## 📊 Visual Status System

| Range | Color | Meaning |
|---|---|---|
| Title 0–50 chars | 🟢 Green | Safe — good length |
| Title 51–60 chars | 🟠 Orange | Near limit — review recommended |
| Title 61+ chars | 🔴 Red | Over limit — will be truncated |
| Description 0–140 chars | 🟢 Green | Safe |
| Description 141–160 chars | 🟠 Orange | Near limit |
| Description 161+ chars | 🔴 Red | Over limit |

## 💡 SEO Tips Included

The tool includes 8 built-in beginner tips:

1. **Be Keyword-Focused** — Place primary keyword near the start
2. **Show Clear Value** — Add a benefit in the description
3. **Avoid Keyword Stuffing** — Write naturally for humans
4. **Keep It Concise** — Stay within limits to avoid "…" truncation
5. **Add a Call to Action** — Use words like "Learn", "Discover", "Get"
6. **Match Search Intent** — Align snippet with what users seek
7. **Include Brand Name** — Builds trust and recognition
8. **Think Mobile First** — Most important words in first 50 characters
